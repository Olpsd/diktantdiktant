# Тренажёр «Пишем на слух» — 2 класс

Открыть: https://olpsd.github.io/diktantdiktant/

Разделы: диктант на слух (пишем в тетради, проверяем по образцу), звуки-близнецы, собери слово, правила, запомни слова, мои успехи.
Голос — встроенный синтезатор речи устройства (нужен русский голос).

## Счёт

Открыть: https://olpsd.github.io/diktantdiktant/schet/

Сложение и вычитание в пределах 10/20/30/40, в строку и в столбик, копилка робуксов (0,5 за пример с первой попытки).

## Читаем вслух

Открыть: https://olpsd.github.io/diktantdiktant/chtenie/

Ребёнок читает рассказ в микрофон (Google Chrome на Android), прочитанные слова закрашиваются зелёным. 0,1 R$ за слово и 0,2 R$ за ответ на вопрос, только за первое прочтение.
