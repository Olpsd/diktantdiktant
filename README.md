# Тренажёр «Пишем на слух» — 2 класс

Открыть: https://olpsd.github.io/diktantdiktant/

Разделы: диктант на слух (пишем в тетради, проверяем по образцу), звуки-близнецы, собери слово, правила, запомни слова, мои успехи.
Голос — встроенный синтезатор речи устройства (нужен русский голос).
